# 创作方向与动态反馈

## 提案怎么写（S2）

**你是设计师。** 用户给的是约束（用途、角色、偏好），不是设计说明书；不要等着被逐项指示。

先提取素材，再出方案：

1. **读语境**：卡牌本地化、角色设定、现有同类特效、调用代码。不改玩法与结算。
2. **定主体**：一句话说清"玩家第一眼看到什么"。主体是一个轮廓/运动，不是一堆层。辉光、火花、烟只服务主体，不必凑满五层。
3. **找意象**：从角色取 1–2 个可见物（音符、琴弦、舞台光、雨滴），让它在**形状、运动或节奏**里起作用——只换主题色不算意象。同一角色已有特效的视觉语言尽量延续，形成系列感。
4. **写三个方向**：必须真的不同（几何刚硬 / 有机流动 / 节奏驱动…），不是一个方案的三个亮度。
5. **出图**：用 `preview_candidates.py` 的 `composition` 按预计染色、尺寸、混合拼一帧静态合成图。节奏是方案关键时（脉冲跟拍、拖尾长度），可以在 `.scratch/vfx/` 搭只含图层的原型场景录 ≤2s mp4。
6. **标代价**：素材数、放大倍数、实现复杂度各一句。用户不懂技术术语，但看得懂"要多找 2 张素材"。

每个方案在回复里这样呈现（文字短，图是主体）：

> **封闭的音符** —— 一圈五线谱环绕着她，音符沿环流动，命中时环向内收一下。
> （预演图）四层：环 + 音符 + 柔光 + 中心闪。0.42 秒。

不要列参数表；参数放计划里。用户回"选 A / A 的环 + B 的节奏 / 都不对"都算收敛。

## 为什么这个效果属于这个角色

计划里要能回答，且不是一句"因为她是键盘手"：

- **表达什么**：触发原因、作用对象、单次/多次视觉峰值是否对应实际效果。
- **意象在哪里起作用**：形状？运动？节奏？只染了主题色的方案要重做。
- **谁是主体**：主要轮廓与视觉焦点；装饰不得抢焦点。
- **保留与避免**：用户明确排除的白闪/烟/规则几何，模板默认值不得覆盖。

## 参考拆解

用户提供图或视频时，提取以下维度；只有图片就不要假定其运动和节奏：

| 维度 | 记录什么 |
|---|---|
| 形状 | 主体轮廓、尖锐/柔软、对称/偏向、实心/留空 |
| 颜色与质感 | 主色、明暗关系、边缘、发光/不发光、颗粒/笔触 |
| 运动 | 从哪到哪、方向性、扩张/收缩、轨迹；动态参考才有直接证据 |
| 节奏 | 蓄势、峰值、停留、收尾；区分想保留的动作与参考中的背景元素 |

不默认照搬整张参考。记录"喜欢什么""避免什么"；素材候选服务于方向，库里某张图好看不能成为改掉用户意图的理由。

## 正常速度验收（S5.2）

至少按正常速度观看完整一轮，再用关键帧定位问题。单帧符合时间和形状要求，仍可能整体拖沓或缺少主次。

- 第一眼能否辨认主体，装饰是否抢走注意力。
- 运动是否表达意图，峰值是否落在批准的触发时刻；单次表现是否出现意外的第二次冲击。
- 如有蓄势，是否帮助下一次峰值；不强制每个效果都加蓄势。
- 收尾是否连贯，有无突然停住、突兀消失或过长余韵。
- 循环是否无意外接缝；一次性效果是否完整结束。

机器冻结告警仅为线索，不能证明"不好看"；持续静态护盾等效果按批准预期判断。不能实际观看视频时明确这一项未完成，不能从抽帧宣布节奏通过。

## 将反馈转成可验证假设

不要把所有反馈都转成增加亮度/粒子。先对照上版定位主要问题，优先每轮验证一个假设。

| 用户反馈 | 先检查的原因 | 候选调整 |
|---|---|---|
| 太散 | 主体不集中、散射范围/尾迹过大 | 缩小散射、减少离主体很远的装饰，保留核心 |
| 不够有力 | 峰值过平、扩张太匀、方向不清 | 拉开峰值与尾段对比、加快初段运动；亮度只是候选 |
| 太廉价 | 过曝、规则层堆叠、粒子大小一致、素材纹理不合 | 降低装饰密度，保住轮廓，调整粒子尺度/节奏差异 |
| 太吵 | 层层抢焦点、重复闪、尾段占比大 | 削弱陪衬，合并峰值，减少重复冲击 |
| 太慢 | 入场等待长、动作匀速、收尾拖长 | 区分入场/主体/尾段后调整曲线或时长，不改玩法结算 |
| 不像这个角色 | 只用了主题色、意象没有参与运动 | 回到角色意象与参考保留点，改变主体需重新确认 |

每轮记录问题、假设、旧值/新值、视频/关键帧证据和结论。先查授权包络；没有授权的参数或超出范围时重新确认，不能用"修观感"扩大授权。
