# 创作方向与动态反馈

## 从角色与玩法提取方向（S0–S2）

先读用户已有描述、相关卡牌本地化与现有特效，不增加额外玩法。不需要重复问已经明确的色彩、风格、意象。

计划应说明：

- **表达什么**：触发原因、作用对象、获得状态/命中/持续等语义，单次与多次视觉峰值是否对应实际效果。
- **为什么属于这个角色/卡牌**：取 1–2 个可见意象，如音符、琴弦、舞台光、雨滴；明确它们在形状、运动或节奏中的作用，不能只换主题色。
- **谁是主体**：主要轮廓与视觉焦点；辉光、火花、烟雾服务于主体，不强制凑齐五层。
- **保留与避免**：必须保留的特色、用户明确排除的白闪/烟/规则几何等；模板默认值不得覆盖这些约束。

只有缺失信息会改变创作方向时才补问，一次一个问题，给具体可见选项。用户说“你决定”就依据已有意象提出默认方案。

## 参考拆解

用户提供图或视频时，提取以下维度；只有图片就不要假定其运动和节奏：

| 维度 | 记录什么 |
|---|---|
| 形状 | 主体轮廓、尖锐/柔软、对称/偏向、实心/留空 |
| 颜色与质感 | 主色、明暗关系、边缘、发光/不发光、颗粒/笔触 |
| 运动 | 从哪到哪、方向性、扩张/收缩、轨迹；动态参考才有直接证据 |
| 节奏 | 蓄势、峰值、停留、收尾；区分想保留的动作与参考中的背景元素 |

不默认照搬整张参考。记录“喜欢什么”“避免什么”；仅在方向不明确时补问。素材候选服务于方向，库里某张图好看不能成为改掉用户意图的理由。

## 正常速度验收（S5.2）

至少按正常速度观看完整一轮，再用关键帧定位问题。单帧符合时间和形状要求，仍可能整体拖沓或缺少主次。

- 第一眼能否辨认主体，装饰是否抢走注意力。
- 运动是否表达意图，峰值是否落在批准的触发时刻；单次表现是否出现意外的第二次冲击。
- 如有蓄势，是否帮助下一次峰值；不强制每个效果都加蓄势。
- 收尾是否连贯，有无突然停住、突兀消失或过长余韵。
- 循环是否无意外接缝；一次性效果是否完整结束。

机器冻结告警仅为线索，不能证明“不好看”；持续静态护盾等效果按批准预期判断。不能实际观看视频时明确这一项未完成，不能从抽帧宣布节奏通过。

## 将反馈转成可验证假设

不要把所有反馈都转成增加亮度/粒子。先对照上版定位主要问题，优先每轮验证一个假设。

| 用户反馈 | 先检查的原因 | 候选调整 |
|---|---|---|
| 太散 | 主体不集中、散射范围/尾迹过大 | 缩小散射、减少离主体很远的装饰，保留核心 |
| 不够有力 | 峰值过平、扩张太匀、方向不清 | 拉开峰值与尾段对比、加快初段运动；亮度只是候选 |
| 太廉价 | 过曝、规则层堆叠、粒子大小一致、素材纹理不合 | 降低装饰密度，保住轮廓，调整粒子尺度/节奏差异 |
| 太吵 | 层层抢焦点、重复闪、尾段占比大 | 削弱陪衬，合并峰值，减少重复冲击 |
| 太慢 | 入场等待长、动作匀速、收尾拖长 | 区分入场/主体/尾段后调整曲线或时长，不改玩法结算 |
| 不像这个角色 | 只用了主题色、意象没有参与运动 | 回到角色意象与参考保留点，改变主体需重新确认 |

每轮记录问题、假设、旧值/新值、视频/关键帧证据和结论。先检查批准的调整范围；没有授权的参数或超出范围时重新确认，不能用“修观感”扩大授权。
