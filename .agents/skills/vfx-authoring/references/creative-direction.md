# 创作方向、动态设计与减法

## 1. 先写动作句，再谈层结构

从卡牌本地化、角色设定、调用代码与同类效果提取语境，然后用一句话说清玩家会看到什么：

> 琴弦般的细线向命中点收束，接触瞬间绽开一个不对称音爆，余光沿来路迅速退回。

动作句应包含**主体、方向与峰值**，再决定贴图与层结构。

默认做一个主方向；只有主体或运动存在真实分歧时才加对照。

## 2. 动态草样是主要提案

用基础几何、工程已有素材或粗贴图，在 `.scratch/vfx/` 做通常不超过 2 秒的原型。按预计实际尺寸与代表性背景原速观看。

拆解时关注：

| 维度 | 要回答的问题 |
|---|---|
| 主体 | 第一眼看到哪个轮廓或动作？何时最清楚？ |
| 方向 | 力从哪里来、往哪里去？轨迹是否服务玩法与角色？ |
| 节奏 | 是否有必要蓄势？峰值多短？有没有停留或第二次冲击？ |
| 速度差 | 峰值与尾段是否有对比，还是所有层一起匀速缩放淡出？ |
| 收尾 | 是收束、破裂、回落还是消散？是否有无信息的长尾？ |

不强制每个效果都有白闪、冲击环、火花、烟或蓄势。静态合成可辅助看造型和颜色，但不能证明动态成立。

## 3. 角色意象必须参与动作

计划里要能回答「为什么这个效果属于这个角色」，且不能只是「因为她是键盘手」或「用了角色色」。

- 从角色取 1–2 个可见意象，如音符、琴弦、舞台光、雨滴；
- 让意象进入**形状、运动或节奏**，例如收束像琴弦绷紧、峰值像断弦，而不是在通用爆散上放几个音符；
- 延续同一角色已有效果的视觉语言，但不要复制同一个层模板；
- 同屏有其他角色效果时，主体轮廓与运动也应有区分度，不只靠色相。

## 4. 参考拆解与对照

用户提供图或视频时，只提取有证据的内容：形状、颜色与质感、运动、节奏。只有图片就不要假定其运动；记录「喜欢什么」与「避免什么」，不默认照搬整张参考。

实现后与旧版、参考或本体同类效果在**相同显示尺寸**下对照，检查主体、峰值、角色感与干扰。新版没有明确优势时继续修改或保留旧版。

## 5. 美术化时保留材质与轮廓的多样性

不要默认所有效果都走「灰阶素材 + 角色色 modulate + ADD」。这只是容易控制的一条技术路线，不是质量基准。

- 带色纹理、硬边剪影、透明混合、程序化形状和 shader 都可能更适合主体；
- 有意的洞、深色描边、不规则边缘不是天然缺陷，应在合成与实战中判断；
- 素材的洞、填充率、放大倍数与混合风险仍需核对，但阈值不能代替艺术判断；
- 库内没有合适形态时换来源或制作，不让库存决定设计。

## 6. 减法审查是正式创作步骤

在实战录像中逐层问：**删掉它，会损害主体、节奏或角色意象吗？** 不会就删。

优先删：

- 与主峰值重复的白闪或冲击；
- 不改变轮廓、只增加曝光的辉光；
- 大小、速度、间距完全一致的均匀粒子；
- 与主体无关的音符、星芒、烟雾等符号装饰；
- 已不传达信息却仍在场上停留的尾段。

减法后重新原速观看。层数少不是目标，**没有冗余且主体成立**才是目标。

## 7. 原速实战验收

先按正常速度完整观看，再用慢放或关键帧定位问题。至少判断：

- 主体是否一眼可读，装饰是否抢走注意力；
- 峰值是否落在玩法触发时刻，是否出现意外第二次冲击；
- 实际尺寸下是否遮角色、敌人意图或 UI；
- 连打、群攻、持续或循环时是否过曝、过吵、有接缝；
- 收尾是否连贯，有无突然停住、突兀消失或过长余韵。

单场景灰底录像不能替代实战验收。无法实际观看视频时明确对应项未完成，不从抽帧宣布节奏通过。

## 8. 将反馈转成可验证假设

每轮优先验证一个主要问题，不把所有反馈都转成增加亮度或粒子。

| 反馈 | 先检查 | 优先调整 |
|---|---|---|
| 太散 | 主体不集中、散射与尾迹过大 | 缩小散射，删远离主体的装饰，保住核心 |
| 不够有力 | 峰值过平、运动匀速、方向不清 | 拉开峰值/尾段速度差，缩短峰值，强化方向 |
| 太廉价 | 过曝、规则层堆叠、粒子一致、素材不合 | 降装饰密度，调整尺度与节奏差异，换主体材质 |
| 太吵 | 多层抢焦点、重复闪、尾段过长 | 合并峰值，削弱陪衬，缩短无信息尾段 |
| 太慢 | 入场等待、匀速运动、收尾拖长 | 改动作分段与曲线；区分视觉余韵和结算等待 |
| 不像角色 | 只换主题色、意象未参与动作 | 回到主体形状与运动，不继续加角色符号 |

记录问题、假设、改动、对照证据与结论即可。素材、层数与参数可服务修复自由调整；只有改变用户确认的质量契约时才重新确认。
