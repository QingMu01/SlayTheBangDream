# 观感与草案参数对照

先确定主体动作与动态草样，再用本表调参。数值只是试验起点；角色意象、玩法语义、实际尺寸与实战录像优先。

## 1. 类型 → 先验证的动态问题

| 类型 | 首先验证什么 | 可作为草案起点的视觉时长* |
|---|---|---|
| 命中（hit） | 方向与峰值是否清楚，收尾是否干脆 | 0.20–0.40s |
| 爆炸（explosion） | 主体扩张是否有速度差，余韵是否有信息 | 0.60–1.20s |
| 拾取（pickup） | 运动目标是否明确，是否轻快 | 0.40–0.70s |
| 治疗（heal） | 上升/汇聚等动作是否符合语义 | 0.60–1.20s 或随状态 |
| 护盾（shield） | 轮廓是否稳定可读，是否遮角色 | 按玩法持续 |
| 传送（teleport） | 收缩、转移、出现的位置关系 | 0.50–0.90s |
| 环境氛围 | 是否低调、有变化且不抢战斗信息 | 常驻，按周期变化 |
| UI 反馈 | 是否极快且不挡内容 | 0.10–0.25s |

\* 视觉时长不等于结算等待；尾迹可以存续，但不能拖慢操作感。

## 2. 用户说法 → 可调参数

| 用户说 | 优先试验 |
|---|---|
| 「炸开」 | 尺度可从小到大，缓出如 `e = 1-(1-x)^3`；同时检查方向与峰值，不只看放大 |
| 「一闪就没了」 | 总视觉时长约 0.10–0.15s；快速起落，不做长尾 |
| 「干脆利落」 | 约 0.25–0.40s；缩短无信息停留与尾段 |
| 「有过程感」 | 先增加可读的因果阶段，不是简单把所有 tween 拉长到 1.2s |
| 「炸完还留一会儿烟」 | 仅当余韵服务语义时加烟；让烟晚于主体结束，不重复主峰值 |
| 「柔和」 | 优先降低边缘硬度、速度差与密度，再调 alpha；柔和不等于糊 |
| 「要飘、慢慢散」 | 加方向性位移、适度旋转和速度差，避免所有粒子同步 |
| 「原地闪」 | 尺度可不变，只动 alpha；多次闪烁需有节奏而非随机噪点 |
| 「一格一格闪」 | 用阶跃或固定帧率，不做平滑插值 |
| 「别太吵 / 低调」 | 先删重复峰值与装饰，再降低亮度、密度和寿命 |
| 「要能循环」 | 首尾状态一致；同时原速检查接缝是否可读 |
| 「从中心往外」 | 位移沿明确方向分布，保留大小/速度差异，避免均匀机械放射 |
| 「从外往内收」 | 尺度与位移共同服务收束；alpha 独立设计，不反转淡出公式 |

## 3. 时间词 → 草案区间

| 词 | 视觉时长 |
|---|---|
| 一闪 | 0.10–0.15s |
| 干脆 | 0.25–0.40s |
| 正常 | 0.50–0.70s |
| 有过程 | 0.80–1.40s |
| 很长 | 2.00s+，必须证明长时变化有信息 |

战斗效果超过约 0.5 秒时，重点检查连打重叠和操作节奏，而不是机械截短所有尾迹。

## 4. 曲线与透明度

常见起点：

```text
e_scale = 1.0 - pow(1.0 - local, 3.0)   // 缓出，只是一个候选
fade = pow(local, alpha_pow)             // 插值参数
alpha = Lerp(a0, a1, fade)               // a1 = 0 时淡出到 0
```

- `alpha = Lerp(A0, A1, 1 - x^pow)` 在 `A1 = 0` 时方向相反，会造成最后停在不透明状态；详见主规范。
- 同一属性不要由并行 tweener 重复写入；分段状态可在单一 `TweenMethod` 中求值。
- **不要让所有层共享同一种缩放与淡出曲线。** 主体、闪光、拖尾和余韵应根据职责形成速度差；同步缩放淡出是「素材拼图感」的常见来源。
- 曲线是否合适只看原速动态，不能因为公式常见就当作已验证。

## 5. 混合模式只按素材与目标选择

| 素材与目标 | 起点 |
|---|---|
| 有 alpha，需保留正常颜色与轮廓 | MIX |
| 有 alpha 的白/灰阶发光层 | 可用 ADD，检查过曝与轮廓 |
| 不透明黑底 | 预览可压黑后 ADD；运行时用对应 shader，并按该素材实测阈值 |
| 带烘焙颜色的贴图 | 不默认用 modulate 强行染色；必要时用亮度重建或换处理路线 |
| 白底素材 | ADD/压黑不能自动去白底；换素材或明确处理 |

压黑阈值不是通用常数。给小了会露出旋转亮方块，给大了会吃掉主体边缘；必须按素材与引擎画面核对。

## 6. 调参顺序

1. **主体轮廓与动作**：不对就先改设计，别加装饰。
2. **峰值与节奏**：方向、速度差、对拍、收尾。
3. **尺寸与遮挡**：按实战实际尺寸和同屏数量。
4. **颜色与材质**：角色感、边缘、混合、纹理。
5. **装饰与曝光**：最后才加，并做减法复审。

每轮尽量只验证一个主要假设，保留原速对照。不要通过同时改十几个参数制造「看起来变化很大」的假象。
