# 翻译表：把用户的话变成参数

本文件是 skill 的核心资产。左边是用户观感，右边是候选参数起点；不是通用定律，须结合意象、素材、授权范围与录制结果调整。

参数名与 `vfx_demo_ex1d` 的验证结果一致（该 demo 已实测通过）。**`LIFE` 是总时长，`t0`/`t1` 是归一化时间（0～1）。**

---

## 表 1：类型 → 层结构模板

用户答完 Q1 就能定位到一行。这是**起点**，不是终点。

| 类型 | 层结构 | LIFE | 循环 |
|---|---|---|---|
| 命中（hit） | flash + spark + 短 burst | 0.30s | 否 |
| 爆炸（explosion） | flash + burst + smoke + debris | 1.20s | 否 |
| 拾取（pickup） | 单颗闪光上飘 + 圆环扩散 | 0.60s | 否 |
| 治疗（heal） | 光柱/粒子上升等可选意象 | 1.20s 起点或随状态持续 | 按持续玩法确认 |
| 护盾（shield） | 圆环/罩体等可选形态 | 一次获得或持续状态 | 按玩法确认 |
| 传送（teleport） | 收缩 + 涡流 + 消散 | 0.75s | 否 |
| 环境氛围 | 闪烁场 + 飘落 | 常驻 | **是** |
| UI 反馈 | 极简 1～2 层 | 0.20s | 否 |

## 表 2：风格 → 参数倾向

风格影响层结构和参数倾向；用户明确偏好、角色意象和玩法语义优先于表内推荐。不强制白闪、冲击环或烟层。

| 风格 | 饱和度 | 辉光档 | 核心层 | 烟雾 | 节奏 | 贴图取向 |
|---|---|---|---|---|---|---|
| 二次元 / 卡通 | 中高 | 按观感 | 纯白闪可选；可用清晰剪影/色块 | 少 / 无 | 通常快、干脆 | 按角色意象选形 |
| 写实 | 低 | 中发光 | 暖色核心 | 多层长尾 | 慢、有余韵 | 烟 flipbook、碎片 |
| 像素 | 极简色板 | 弱 / 不发光 | 方块化 | 无 | 帧数少 | 硬边、无羽化 |
| 科技 / 科幻 | 冷 | 强发光 | 六边形 / 网格 | 无 | 匀速机械感 | 框线、几何、扫描线 |
| 手绘 | 中 | 弱发光 | 笔触 | 有 | 带抖动 | 不规则边缘 |
| 自然 | 中低 | 弱发光 | 无 | 有 | 飘、慢 | 叶片、水花、花朵 |
| UI 扁平 | 高 | 不发光不透明 | 纯色块 | 无 | 极快 | 几何图形、框线 |

## 表 3：用户说法 → 技术参数（最重要）

| 用户说 | 落到参数 |
|---|---|
| "炸开" | 尺度 `s0 0.14 → s1 0.66`，缓出 `e = 1-(1-x)^3` |
| "一闪就没了" | `LIFE ≤ 0.12`；`alpha_pow 0.45`（快起快落） |
| "干脆利落" | `LIFE 0.30`；`alpha_pow 0.80` |
| "有过程感" | `LIFE 1.20`；`alpha_pow 1.7` |
| "炸完还留一会儿烟" | 追加 mix 层，尾段 `t1` 晚于 burst；例如 `t0 0.10 / t1 0.70`（归一化，验收须乘 LIFE） |
| "亮瞎眼" | `intensity ≥ 1.15` + 独立 flash 层（`t0 0 / t1 0.11`） |
| "中等亮" | `intensity 1.00`，不加 flash 层 |
| "柔和的雾" | 走 alpha 混合，`alpha 0.28`，`alpha_pow 1.6` |
| "要飘、慢慢散" | 加旋转（`rot 28`）+ 位移；`alpha_pow ≥ 1.6` |
| "原地闪" | `s0 == s1`（不变尺度），只动 alpha；**加随机相位** |
| "一格一格闪" | 用阶跃 / 固定帧率，**不要插值** |
| "别太吵 / 低调" | `intensity ≤ 0.8`；**不加** flash 层 |
| "要能循环" | 首尾状态必须一致，否则接缝跳变 |
| "从中心往外" | 位移沿 `spread` 均匀分布，速度 `dist` 随机 |
| "从外往内收" | 尺度 `s0 1.0 → s1 0.2`；alpha 独立设计入场/退场，不反转淡出公式 |

## 表 5：混合模式决策（**先看这条，能避免 90% 的翻车**）

判据来自 `get_asset` 的 `features` 字段。

| 素材特征 | 混合模式 | 附加参数 |
|---|---|---|
| 透明占比 > 0（有 alpha） | `alpha`（`CanvasItemMaterial.BLEND_MODE_MIX`） | 无 |
| 有 alpha 且要发光叠加 | `alpha_add`（`BLEND_MODE_ADD`） | 无 |
| 透明占比 = 0，黑底 JPG | `crush_add` + 压黑 shader | `black_point` 见下 |
| 含 alpha 的白色/灰阶贴图 | 通常 alpha 或 alpha_add | 保留纹理 alpha；不要用忽略纹理 alpha 的 crush shader |
| 无 alpha 的白底素材 | 先核对背景与用途 | ADD 会叠出亮方块，crush 也不能去白底；换素材或明确处理 |

**以下 black_point 是对应素材的实测起点，不能照搬到所有黑底素材**（JPG 的"黑"不是纯黑，实测 9–20/255）：

| 素材类型 | `black_point` | `softness` |
|---|---|---|
| 爆散图（`T_VFX_Ex1d`） | **0.090** | 0.10 |
| 闪光图（`T_VFX_hit22`） | 0.040 | 0.08 |
| 柔光图（`T_VFX_Glo31`） | 0.035 | 0.07 |
| 碎片 / 火星 | 0.030 | 0.06 |

> `black_point` 给小了会露出**旋转的亮方块**（黑底被加法混合加了上去）。这是本项目最容易踩的坑。

## 推荐默认值（用户说"你决定"时用这套）

一套**已验证可用**的爆炸参数，可直接作为起点：

| 层 | 贴图用途 | 混合 | t0 | t1 | s0 | s1 | a0 | a1 | rot | alpha_pow | z | 压黑 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| glow | 柔光 | crush_add | 0.00 | 1.00 | 0.20 | 0.85 | 0.60 | 0 | 0 | 1.7 | 0 | 0.035 / 0.07 |
| smoke | 烟 flipbook | alpha | 0.10 | 0.40 | 0.60 | 1.10 | 0.28 | 0 | 28 | 1.6 | 10 | — |
| burst | 爆散 | crush_add | 0.00 | 0.34 | 0.14 | 0.66 | 1.00 | 0 | 18 | 0.80 | 20 | 0.090 / 0.10 |
| flash | 闪光 | crush_add | 0.00 | 0.11 | 0.20 | 0.54 | 1.00 | 0 | 12 | 0.45 | 30 | 0.040 / 0.08 |
| spark ×7 | 碎片 | crush_add | 0.00 | 0.50 | 0.10 | 0.35 | 1.00 | 0 | 随机 | 1.2 | 40 | 0.030 / 0.06 |
| trail ×3 | 拖尾 | alpha_add | 0.00 | 0.45 | 0.30 | 0.80 | 0.70 | 0 | 随机 | 1.4 | 35 | — |

配套曲线（单一 `TweenMethod` 内计算）：

```
e_scale = 1.0 - pow(1.0 - local, 3.0)   // 缓出
e_alpha = 1.0 - pow(local, alpha_pow)   // alpha_pow 越小消失越快
```

**单一 tween 铁律**：所有层在同一 `tween_method(_apply_state, 0, 1, LIFE)` 里算，绝不建两个 tweener 写同一属性（见 `docs/vfx-authoring.md` §1 铁律三）。

## 表 6：时长词 → 秒数

| 词 | 秒 |
|---|---|
| 一闪 | 0.10–0.15 |
| 干脆 | 0.25–0.40 |
| 正常 | 0.50–0.70 |
| 有过程 | 1.00–1.40 |
| 很长 | 2.00+ |

> 战斗类特效**超过 0.5 秒可能拖慢观感**（区分视觉余韵与等待结算）。用户说"1 秒左右"时，先确认他是否接受连打时特效重叠。
