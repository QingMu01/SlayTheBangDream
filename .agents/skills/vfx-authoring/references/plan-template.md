# 特效计划模板

用于复杂或全新设计，保存到 `.scratch/vfx/plans/<slug>.md`。

`gate` 块只包含主体、角色意象、峰值、禁区与实战验收；素材、层数、混合、曲线和参数放在块外，可随实现调整。需要正式确认时才运行 `check_gate.py`。

## 3. 实战验收标准

- [ ] 原速实战中主体一眼可读，装饰不抢焦点
- [ ] 角色意象参与形状、运动或节奏，不是通用素材只换色
- [ ] 峰值对拍，无意外第二次冲击；收尾干净
- [ ] 实际尺寸下不遮挡关键角色动作、敌人意图或 UI
- [ ] 预期的连打/群攻/持续情况下不过曝、不吵、不残留

## 可选闸门命令

```bash
# 用户确认质量契约后
python .agents/skills/vfx-authoring/scripts/check_gate.py --plan <plan.md> \
  --approve --approved-by "<用户原话>"

# 实现前校验质量契约未变
python .agents/skills/vfx-authoring/scripts/check_gate.py --plan <plan.md>

# 质量契约本身改变时重开；换素材、删层、调参数通常不需要
python .agents/skills/vfx-authoring/scripts/check_gate.py --plan <plan.md> --reopen
```

确认时只讲玩家会看到什么、峰值与实战约束，并给动态草样。不要念素材表、层表或参数范围。
