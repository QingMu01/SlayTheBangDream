# 访谈问题库（漏斗式，一次一问）

面向**完全不懂特效的用户**。用户只需**认图 / 选选项**，不需要知道任何术语。

## 硬性规则

1. **一次只问一个问题。** 不要在同一轮里抛多个问题——用户会答得草率，而且后面的答案会受前面干扰。
2. **不设轮次上限**，但必须做到两件事：
   - **告知进度**：每次提问都带上「第 N 问 / 预计共约 M 问」与当前层次；
   - **满足收敛条件即停**（见下方「什么时候停」），不要为了问而问。
3. **每题给 2–4 个具体选项（不含逃生口）** + 一句"这看起来是什么样"。
4. **每题必有逃生口**："看不懂 / 你决定"。选了就走推荐默认值，**不再追问**。
5. **禁止问技术问题**——这些是 agent 的决策，不是用户的：
   - ❌ 用加法混合还是 alpha 混合？
   - ❌ 需要几层？z 序怎么排？
   - ❌ 缓动用 ease-out 还是 ease-in-out？
   - ❌ 帧率多少？分辨率多少？
   - ❌ 用哪个 shader？
6. **用户已经说过的不要再问。** 他可能在答第 1 题时顺口说了颜色——记下来，跳到该题时直接跳过，
   并在计划里注明"来自用户第 1 问的自由回答"。
7. **回答矛盾时才追问**（如"一闪而过"+"慢、有拖尾"）。矛盾之外的模糊一律取默认值。

---

## 先利用已有创作方向

S0 先提取用途与角色/卡牌信息，再用 S1 给宽泛参考；Q1 已有答案就跳过。用户给参考时按形状、颜色、运动、节奏、质感拆解喜欢的部分与禁用元素，见 [creative-direction.md](creative-direction.md)。必要时在 Q2 前补一题“最想突出哪种角色/卡牌意象？”，给具体视觉选项；不要强迫用户发明术语。

## 漏斗总览

**从大方向逐层收窄**：先定"这是什么"，再定"长什么样"，最后才定"具体用哪张图"。
顺序不能倒——先问细节会让用户无从答起。

| 层 | 题 | 问什么 | 为什么在这一层 |
|---|---|---|---|
| **L1 大方向** | Q1 | 用途 / 触发时机 | 决定类型模板，并决定后面**问哪些、跳过哪些** |
| **L2 风格与观感** | Q2 | 画风 | 决定层结构与参数倾向（见 translation-tables 表 2） |
| | Q3 | 主色 | 决定染色；能筛掉不可用的素材 |
| | Q4 | 亮度质感 | 决定辉光档位与要不要纯白核心 |
| **L3 运动与节奏** | Q5 | 运动方式 | 决定尺度/旋转曲线 |
| | Q6 | 节奏 / 时长 | 决定 `LIFE` |
| **L4 具体内容** | Q7 | 素材取向（**必须带图**） | 到这一步用户已有足够语境能看图选 |
| | Q8 | 脏元素（烟 / 碎片） | 决定要不要加层 |
| | Q9 | 附加结构（冲击环等） | 按 L1 的类型给选项 |
| **L5 边界（按需）** | Q10 | 是否循环 | 只有氛围/环境类必问 |
| | Q11 | 同屏数量 | 只有用户提到连打、群攻、AOE 时问 |

**典型路径**：L1 → L2（3 题）→ L3（2 题）→ L4（2–3 题）= **约 8 问**；
用户多次选"你决定"时会更少（见收敛条件）。

---

## 什么时候停

满足**任意一条**即可收敛，进入 S2.5 / S3：

1. **已覆盖 L1 + L2 + L3**（类型、风格、主色、亮度、运动、时长都定了）——
   这六项已足够写出可执行的计划，L4/L5 可全部走推荐默认值。
2. **用户主动叫停**："够了 / 直接出计划吧"。
3. **连续两题用户都选"你决定"**——说明他不想被问，继续问只会消耗耐心。
4. **已经问了 10 题仍没收敛**——说明问题设计有问题或有歧义，停下来问一句
   "我可能问偏了，你最在意的是哪一点？"

**收敛时明确告诉用户**："我这边信息够了，接下来会先做素材 1:1 预演，再给你一份计划确认。"

## L1 大方向

### Q1 用途 / 触发时机（决定类型模板与后续分支）

> 第 1 问 / 预计共约 8 问。
> 先问最粗的：**这个特效是干什么用的？**

- **A** 打中敌人 / 自己受伤的时候
- **B** 打出某张牌 / 放技能的时候
- **C** 拿到或使用道具的时候
- **D** 一直挂在那里的氛围（比如场景里的火光）
- **E** 看不懂 / 你决定

**根据答案分叉**（后续问哪些题由这里决定）：

| 答案 | 后续调整 |
|---|---|
| A 命中 | 跳过 Q10（显然不循环）；Q9 按意象选问；冲击环只是候选，不是命中特效必备层；Q6 推荐 0.3–0.5s |
| B 出牌 / 技能 | **缺信息时追加一问**："特效是从角色身上出现，还是要飞出去？"——只确定运动方式。基类仍由 agent 检查调用代码：仅飞行且命中时刻驱动玩法结算时用 `NBangDreamFlyingVfx`，纯视觉飞行仍用 `Node2D` |
| C 拾取 / 道具 | Q9 改问"光点是否向上飘"；Q6 推荐 0.5–0.7s |
| D 环境氛围 | **Q10 必问**（确认持续方式，不预设循环）；跳过 Q9（氛围类没有冲击环）；Q6 改问"变化周期" |
| E 你决定 | 按命中处理，并在计划里标 `[默认值]` |

## L2 风格与观感

### Q2 画风（决定层结构与参数倾向）

> 第 2 问。**更接近哪种画风？**

- **A** 二次元 / 卡通（颜色鲜艳、干脆、带纯白闪）
- **B** 写实（颜色偏暗、烟多、有余韵）
- **C** 科技感（冷色、几何、机械）
- **D** 手绘 / 自然（不规则、飘逸）
- **E** 看不懂 / 你决定

### Q3 主色（决定染色）

> 第 3 问。**主色想要哪种？**

- 根据角色主题色和已有偏好给 2–4 个具体色彩方案，并给“看不懂 / 你决定”；没有线索时可用暖橙金、冷蓝青、紫粉、纯白。多彩意图不得被强制改成单色。

> 这一步同时帮你筛素材：**白色或中性灰阶贴图适合乘算染色**，
> 带色贴图（如橙金）染冷色会发暗。所以问了主色才知道该找哪类素材。

### Q4 亮度质感（决定辉光档位与是否加纯白核心层）

> 第 4 问。**看起来有多亮？**

- **A** 亮瞎眼，强发光、有纯白的核心
- **B** 中等亮，有明显光晕
- **C** 柔和的雾 / 烟，不刺眼
- **D** 很淡，几乎看不出在发光
- **E** 看不懂 / 你决定

**分支**：

- 选 **C** → 根据意象判断是柔光、雾还是烟；用户只说柔和时不自动添加烟层；
- 选 **A** → 推荐亮核心；纯白闪只是候选手段，已有低调/禁白闪约束优先；
- 选 **D** → 只剩 1–2 层，跳过 Q9，并提醒用户"这样的特效在战斗里几乎看不见"。

---

## L3 运动与节奏

### Q5 运动方式（决定尺度 / 旋转曲线）

> 第 5 问。**它主要是什么动作？**

- **A** 从中心炸开、往外扩散
- **B** 从外面往中心收缩
- **C** 原地一闪一闪
- **D** 一边转一边动
- **E** 看不懂 / 你决定

**分支**：选 **D** 时补一句"旋转幅度要不要大？"（决定 `rot` 是 10° 还是 180°+）。

### Q6 节奏 / 时长（决定 `LIFE`）

> 第 6 问。**它持续多久？**（按 Q1 的类型给不同的推荐项）

| Q1 类型 | 推荐选项措辞 |
|---|---|
| 命中 | 一闪就没了（<0.2s） / **干脆利落（0.3–0.5s）** / 有过程感（约 1s） |
| 出牌 | 干脆（0.4s） / **有过程感（0.6–1.0s）** / 很长（1.5s+） |
| 拾取 | 轻快（0.4–0.6s） / **明显一点（0.6–0.8s）** |
| 氛围 | 改问"**变化周期**多长"（2s / 4s / 8s）——氛围类不问总时长，问循环周期 |

> 战斗类特效**超过 0.5 秒可能拖慢观感**（尾迹时长与等待结算时长分别判断）。用户选"1 秒左右"时补一句确认：
> "连打时会叠在一起，你接受吗？"

## L4 具体内容

### Q7 素材取向（**必须先跑 S1 拿到候选图，且必须附图**）

> 第 7 问。**我翻了下你的素材库，这几张比较接近。你想要哪种感觉？**
>
> （**内联联络表 / 预演图**，图内带编号）

- **A** `#1` —— `<一句话形态描述>`
- **B** `#2` —— …
- **C** `#3` —— …
- **D** 都不是，我另外描述
- **E** 你决定

> 候选必须来自 `render_contact_sheet` 的真实结果，写进计划时带 uuid。
> **不能只给资产名**——用户看不懂 `base_glow` / `star_04` 这类名字。见 SKILL.md「展示优于命名」。

### Q8 "脏"元素（决定要不要加层）

> 第 8 问。**除了光，要不要烟、雾、碎片这类东西？**

- **A** 干净，只有光
- **B** 加一点碎片火星
- **C** 加烟
- **D** 很多烟和碎片，很混乱
- **E** 看不懂 / 你决定

> 若 Q4 选了"柔和的雾"，本问默认 C，直接跳过。

### Q9 附加结构（按 Q1 类型给选项）

> 第 9 问。**要不要加一圈向外扩散的冲击环？**（命中类）

- **A** 要，加一圈冲击环
- **B** 不要，只留闪光和爆散
- **C** 看不懂 / 你决定

其他类型的替换问法：

| 类型 | 问法 |
|---|---|
| 拾取 | "光点要不要向上飘？" |
| 技能 | "中心要不要一个亮点作为视觉焦点？" |
| 氛围 | 跳过（无附加结构） |

## L5 边界（按需，通常 0–2 题）

### Q10 是否循环（**只有环境氛围类必问**）

> **它需要能一直循环吗？**

- **A** 不需要，放一次就完
- **B** 需要，要能一直循环
- **C** 看不懂 / 你决定

> 循环类必须保证**首尾状态一致**，否则接缝跳变。

### Q11 同屏数量（**只有用户提到连打、群攻、AOE 时问**）

> **同一时刻屏幕上最多可能同时有几个？**

- **A** 就 1 个
- **B** 几个（2–5）
- **C** 很多（10 个以上）
- **D** 看不懂 / 你决定

> 选 C 时必须降粒子数、缩短寿命、避免高分辨率贴图。

## 进度提示话术

因为不设轮次上限，**每次提问都要让用户知道还有多久**：

> 第 3 问 / 预计共约 8 问 —— 主色想要哪种？

某项用户说"你决定"后，进度会缩短，可以顺手更新：

> 第 5 问 / 预计还剩 2～3 问 —— 它主要是什么动作？

收敛时明确收尾：

> 信息够了（第 7 问结束）。接下来我先做素材 1:1 预演，再给你一份计划确认。

---

## 用户说"随便 / 你看着办"时怎么办

不要继续追问。该题直接走推荐默认值，并：

1. 在 `plan.md` 里把每个 `[默认值]` 逐条标出。
2. 在 S4 讲计划时**一次性**把这些默认值念给用户听，让他确认或挑几个改。
3. **连续两题都是"你决定"就整体收敛**——用户说"随便"通常是不想被问，不是真的没有偏好。

---

## 矛盾时的追问话术

只在真矛盾时追问，且给**二选一**而不是开放问题：

> 你前面说"一闪就没了"，但又说"慢、有拖尾"——这两个不太能同时成立。
> 你是想要 **A** 很短很干脆（0.2 秒）还是 **B** 稍微留个尾巴（0.5 秒左右）？

---

## 用户提前回答时怎么办

一次一问的访谈里，用户经常会**顺口答了后面的题**（比如答 Q1 时说了"要蓝色的"）。

处理：**记下来，跳到该题时直接跳过**，并在计划里注明来源：

```markdown
- 主色：冷蓝青（来自用户第 1 问的自由回答，未单独提问）
```

不要因为"流程规定要问 Q3"就再问一遍——那是最容易让用户烦躁的行为。
