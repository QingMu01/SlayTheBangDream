# 三屏选择（guided 模式专用）

**默认不做访谈，做提案**（见 SKILL.md §7）。本文件只在用户明确说"你问我吧 / 我说不清 / 给我选项"时使用。

## 规则

1. **一屏 2–3 题，共三屏。** 不要拆成一次一问的十几轮——用户答得草率，来回也慢。把同屏的题一次列全，让他一起回。
2. **每题给 2–4 个具体选项 + "你决定"逃生口。** 选项要"看到就知道是什么"，不是术语。
3. **不问技术问题。** 混合模式、层数、z 序、缓动、帧率、shader 都是 agent 的决策。
4. **不问用途与触发。** 从卡牌本地化、现有实现、调用代码读；读不出才补一句。
5. **用户已经说过的不要再问**；同一屏里题目可以合并讲，别把用户的回答当成"没答"。
6. **每屏开头给一句进度**（"第一屏：观感。三屏之后我出计划"），不要报"第 N 问 / 共 M 问"。

## 第一屏：观感

> 先定它长什么样。三屏之后我会给你一份带图的方案确认。

**Q1 画风**（决定层结构与参数倾向）

- **A** 二次元 / 卡通：颜色鲜艳、干脆、带纯白闪
- **B** 写实：颜色偏暗、烟多、有余韵
- **C** 科技感：冷色、几何、机械
- **D** 手绘 / 自然：不规则、飘逸
- **E** 你决定

**Q2 主色**（决定染色与选素材）

按角色主题色给 2–4 个**色条/小图**；无线索时用暖橙金、冷蓝青、紫粉、纯白。多彩意图不能被压成单色。

> 白色或中性灰阶贴图适合乘算染色，带色贴图染冷色会发暗——所以主色先定，再找素材。

**Q3 亮度质感**（决定辉光档位与要不要纯白核心）

- **A** 亮瞎眼，强发光、有纯白核心
- **B** 中等亮，有明显光晕
- **C** 柔和的雾 / 烟，不刺眼
- **D** 很淡，几乎看不出在发光（提示：战斗里会几乎看不见）
- **E** 你决定

## 第二屏：节奏

**Q4 运动方式**（决定尺度 / 旋转曲线）

- **A** 从中心炸开、往外扩散
- **B** 从外面往中心收缩
- **C** 原地一闪一闪
- **D** 一边转一边动（追问一句：转 10° 左右，还是大半圈？）
- **E** 你决定

**Q5 时长**（决定 `LIFE`，按类型给推荐项）

| 类型 | 选项措辞 |
|---|---|
| 命中 | 一闪就没了（<0.2s） / **干脆利落（0.3–0.5s）** / 有过程感（约 1s） |
| 出牌 / 技能 | 干脆（0.4s） / **有过程感（0.6–1.0s）** / 很长（1.5s+） |
| 拾取 / 道具 | 轻快（0.4–0.6s） / **明显一点（0.6–0.8s）** |
| 氛围 / 环境 | 不问总时长，问**变化周期**（2s / 4s / 8s） |

> 战斗类超过 0.5 秒可能拖慢观感（尾迹时长与等待结算时长分别判断）。用户选"1 秒左右"时补一句："连打时会叠在一起，你接受吗？"

## 第三屏：内容

**Q6 素材取向**（**必须先跑 S1，必须内联联络表/预演图，图内带编号**）

- **A** `#1` —— `<一句话形态描述>`
- **B** `#2` —— …
- **C** `#3` —— …
- **D** 都不是，我另外描述
- **E** 你决定

> 候选必须来自 `render_contact_sheet` 真实结果，写进计划时带 uuid。**不能只给资产名**——用户看不懂 `base_glow` / `star_04`。

**Q7 要不要"脏"元素**（决定加不加层）

- **A** 干净，只有光
- **B** 加一点碎片火星
- **C** 加烟
- **D** 很多烟和碎片，很混乱
- **E** 你决定

> 第一屏选了"柔和的雾"→ 默认 C，可以跳过。

**Q8 附加结构**（按类型问法，命中类才问环）

| 类型 | 问法 |
|---|---|
| 命中 | 要不要加一圈向外扩散的冲击环？（A 要 / B 不要 / C 你决定） |
| 拾取 | 光点要不要向上飘？ |
| 技能 | 中心要不要一个亮点做视觉焦点？ |
| 氛围 | 跳过（无附加结构） |

## 停下来

第三屏答完就停，进入 S2.5 / S3：

> 三屏答完了，信息够用。我先核一遍素材，再给你计划确认。

提前收敛的条件（任一满足即停）：

1. 观感 + 节奏已定（画风、主色、亮度、运动、时长）——内容屏全部走推荐值；
2. 用户主动说"够了 / 直接出计划"；
3. 连续两屏都选"你决定"——说明他不想被问，继续问只是消耗耐心。

## 逃生口与矛盾

- 选"你决定"：走推荐默认值，**不再追问**；在计划"决策与默认值"里标 `[自定]`，S4 一次性念给用户听。
- 连续两屏都是"你决定"：整体收敛，不要逐题追。
- 真矛盾才追问，且给**二选一**：

> 你说"一闪就没了"，又说"慢、有拖尾"——这两个不太能同时成立。你要 **A** 很短很干脆（0.2 秒）还是 **B** 留个尾巴（0.5 秒左右）？

- 用户顺口答了后面的题（"要蓝色的"）：记下来，到那题直接跳过并在计划里注明来源，不要按流程再问一遍。

## 其余边界问题（按需，最多一句）

- **循环**：只有氛围/环境类必问。循环必须首尾状态一致，否则接缝跳变。
- **同屏数量**：只有用户提到连打 / 群攻 / AOE 时问。选"很多"时必须降粒子数、缩寿命、避免高分辨率贴图。
