# 集中提问（仅 guided 模式）

**默认不访谈，直接做有主张的动态草样。** 只有用户明确说「你问我吧 / 我说不清 / 给我选项」时使用本文件。

## 规则

1. **最多一屏、四个问题。** 只问会改变主体或运动、且无法从仓库与上下文读出的内容；不要拆成多轮。
2. 每题给 2–4 个具体选项与「你决定」。能附图/色条就附，不问混合模式、层数、z 序、shader、曲线等技术问题。
3. 不问已回答的用途、触发、角色和偏好；这些先从本地化、调用代码与现有实现读取。
4. 用户说「够了 / 你决定」立即收敛，不补问剩余题。
5. 问完后直接做动态草样；不要让用户先逐张决定素材，再替模型完成设计。

## 按需选择的四个问题

### Q1 主体与禁区（最重要）

> 你最想看到哪种主体动作？有没有明确不要的东西？

选项应按当前角色与卡牌具体生成，例如：

- **A** 细线收束后短促绽开，强调方向与命中
- **B** 不规则音符沿轨迹翻动，强调角色与流动
- **C** 你决定
- 禁区示例：白闪 / 烟 / 规则圆环 / 遮脸 / 长尾

### Q2 参考与质感

> 有没有想接近的已有效果、卡面或参考？想保留的是轮廓、颜色还是质感？

只有图片参考时不让用户描述参考里不存在的运动；运动由 Q3 或草样解决。没有参考就由模型决定。

### Q3 运动与节奏

> 动作更接近哪一种？

- **A** 快起快落，峰值很短，收尾干净
- **B** 先有可读的收束/蓄势，再一次峰值
- **C** 有明显后续运动或余韵，但不拖慢结算
- **D** 你决定

若用户已给明确时长或「一闪就没」，跳过。不要把「有过程感」机械翻译成所有层一起变慢。

### Q4 实战强度

> 在实际战斗里希望它多显眼？是否经常连打或群攻？

- **A** 很清楚但尽量低调，不遮角色和 UI
- **B** 峰值突出，尾段迅速让位
- **C** 强调华丽，接受较明显的发光与重叠
- **D** 你决定

能从卡牌触发与玩法代码确认同屏数量时，不问后半句。

## 问完之后

用回答写一句主体动作与质量契约，然后做原速动态草样。只有方向仍存在真实分歧时才请用户看草样做一次选择；否则直接进入美术化与实现。
