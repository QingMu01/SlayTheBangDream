# 特效计划：破绽 / 弱点击破（裂纹积累）

## 1. 设计意图

破绽是「被打出来的弱点」，攒满 4 层就变成「弱点击破」——要让玩家看到**裂纹在目标身上越长越多**，第 4 层时整块碎裂并持续暴露。它挂在任意单位身上（敌我皆可），所以必须低干扰、可长时间共存，且不遮住血条/意图/血量数字。

- 触发/对象：`BreakCmd.Discover` 每次生效 → 刷新层数；满 4 层 → 一次性「碎裂」；`WeakPointBreakPower` 移除 → 淡出。
- 对象：任意 `Creature`（锚在其命中框上缘）。
- 角色意象来源：破绽＝弱点暴露；不借用墨缇丝的提线/冰霜语言（那是玩家的私有符号）。
- 不改变的：层数上限、弱点击破 1 回合、击破触发时机、VFX 的 Hover tips 行为。
- 用户已表达的偏好：**不做 Power 图标**，只做常驻 VFX；Hover 时弹能力同款 tips。

## 4. 验收标准（契约）

- [ ] 1–3 层：指示点数量与层数一致、细裂纹数量与层数一致；层数变化 0.12s 内有 pop 反馈
- [ ] 第 4 层：0.30s 内算出「整块碎裂」——覆盖层到 0.75 alpha、碎片闪光在 0.135s 前消失
- [ ] 弱点击破期间覆盖层保持 0.22–0.34 的呼吸，不遮住目标血条、意图图标与受击飘字
- [ ] 退出后 0.35s 内所有层消失、节点被释放；目标死亡时同样不残留
- [ ] Hover 仍能弹出能力同款 tips（VFX 只吃悬停、不吃点击与拖拽：`MouseFilter = Pass`）
- [ ] 同一屏幕多个目标各自独立（≥3 个目标同时破绽，节点不串、不共享状态）
- [ ] 玩家侧目标（破绽可施加给任意单位）同样正常显示，不遮挡手牌区
- [ ] 覆盖层黑底压黑有效：正常速度播放不出现可见的旋转亮方块
- [ ] 与敌方自带的受击/死亡特效叠加时不过曝（出现明显白屏即修）

## 5. 授权包络（契约）

| 参数 | 本计划基准 | 可调整范围 | 不可改变的约束 |
|---|---|---|---|
| LIFE（进入/退出） | 0.30s / 0.35s | ±40% | 不延迟任何玩法结算（纯表现） |
| 各层显示尺寸 | 见 §3 | ±30% | 覆盖层仍以命中框为基准自适应 |
| alpha 峰值 | 见 §3 | ±0.25（0–1 内） | 不遮住血条/意图/数字 |
| 旋转角度 | 碎片闪光 10° | ±15° | 覆盖层不旋转（避免出现旋转方框感） |
| 装饰层（细裂纹/闪光） | 见 §3 | 可增删 | 不影响主体（覆盖层 + 指示点） |

**不可改，改了要重新确认**：素材集合、主体形态（裂纹覆盖 + 菱形层数点）、用途/触发与结算时刻、核心层数量（覆盖层与指示点必留）。

## 8. 假设与风险（不锁）

- 覆盖层挂在敌方身上时与受击特效叠加，峰值可能过曝；进入段 alpha 上限 0.75 已预留余量。
- 破绽可施加给玩家侧单位；玩家命中框较窄时按自适应口径缩到 180px，指示点间距同步收紧（避免 4 点超出框宽）。
- 若同屏破绽目标超过 5 个，呼吸同步会形成节奏感过强；实现时给每个实例 ±15% 相位抖动（属包络内）。
- `T_Cracks336` 的亮心在原图正中；压黑后与目标胸口对齐，需在实现时按命中框中心偏移，避免亮心落在头顶。
