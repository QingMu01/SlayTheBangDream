# 睦三套特效 · 实现期调参与偏离记录

> 记录范围：2026-11-14 批准 → 同日实现。所有改动都在「不换素材、不改主体形态、不改触发与结算时刻、不减核心层」的前提下。
> 标 **[偏离]** 的项超出计划 §5 授权包络，附理由与批准图依据，需用户过目。

## 渲染与验收方式

- 沙箱无 Steam 部署目录（只读），无法进战斗实机；改用 Godot `--write-movie --fixed-fps 60` 单独渲染三个预览场景取帧：
  - 冻结 42 帧 / 激活 130 帧 / 破绽 340 帧（预览时间线 1/2/3 层 → 弱点击破 → 清空）
  - 交付：`.scratch/vfx/out/mutsumi_{freeze,activation,break}.mp4` + `.gif`
- 渲染环境注意：Vulkan 不可用会自动回落 OpenGL3；`XDG_*` 指向 `.scratch/godot-home/` 才能写出日志，否则启动即崩溃。
- 仍然缺的：真实对局中的观感（演奏区真卡图、与战斗背景/受击特效叠加、多目标破绽）。

## 一、歌单冻结（提线悬停）

| 项 | 计划基准 | 实现 | 说明 |
|---|---|---|---|
| 主线上端距离 | 组包围盒上方 60px | **200px + 顶端 α 渐隐** | **[偏离]** 60px 只有 44px 长的短桩，读不出「从上方落下来」；批准预演图里线是从画面上方垂下的，按图实现 |
| 槽位降亮 | 占位 0.62/0.76/0.95 | 0.82/0.84/0.92 | 占位色相乘过重，与预演里「行仍可读、整体偏紫」不符 |
| 四组锚点比例 | — | C .18 / D .78 / F .22 / G .82 | 同列两组若同 x，两条主线会完全重合 |
| 行倾斜 | 预演图有 2.5–3.5° 倾斜 | **不倾斜** | 行由 NPerformArea 的布局缓动与镜像管，接管旋转会与缓动/命中框冲突；靠线略垂 + 吊点高光表达悬挂 |
| 覆盖层 | 计划里的紫灰覆膜 | `glow_soft` 拉伸覆盖包围盒 40px，α 0.10 | 单张软光足够，未新增素材 |

## 二、分组激活（提线收紧）

| 项 | 计划基准 | 实现 | 说明 |
|---|---|---|---|
| 行点亮填充 | 0.55–0.70 描边 | 底色 0.22、描边 2.2px α 0.9 | 首版只有细描边，预览里几乎看不出「三条行亮了」 |
| 扫光 alpha | 0.75 | 0.90 | 同上，GIF 里扫光太弱 |
| 一次性 LIFE | 0.40s | 0.40s | 未变 |
| 静态环/星尺寸 | 62→104 / 96→128 | 同计划 | 未变 |

## 三、破绽（裂纹积累）

| 项 | 计划基准 | 实现 | 说明 |
|---|---|---|---|
| 碎裂覆盖 / 碎片闪光 | `_Draw` 里画贴图 | **Sprite2D + CanvasItemMaterial.Add** | 黑底不透明图直接 `_Draw` 会盖住下层并留下不透明方块；加法混合后才只剩裂纹与闪光 |
| 层数点半径 | 5 | 6.5 | 5 在 1080p 下太小，读不清层数 |
| 细裂纹 | α 0.35 / 长 ≤46px / 宽 2.2 | α 0.45 / 长 ≤64px / 宽 2.8 | 唯一能表达「越裂越深」的层，太细就看不出递增 |
| 层数 pop | 0.12s | 层数变化与进入破击都触发 | 计划只写了进入破击的 pop |
| 预览时间线 | — | 1/2/3 层 → 破击 → 清空，各停 1.2s | 供 F6 自查；预览态也必须推进一次性计时，否则停在第一帧 |

## 待用户在实机确认的点

1. 冻结：四条主线从画面上方落下的长度是否合适（200px）；紫色覆膜在深色战斗背景上是否偏暗。
2. 激活：0.40s 内「行亮 → 扫光 → 线拉出 → 光点跑回」是否太快；四根线常驻时会不会显得乱。
3. 破绽：满 4 层的碎片闪光在深色背景上是否过亮；呼吸 0.22–0.34 在敌人身上是否足够显眼。
